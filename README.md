# 🚀 FitLog

A modern and interactive fitness tracking web application where users can explore different workouts, view detailed workout information, create a personal workout plan, and save their favorite workouts.

## ✨ Features

* 🏋️ Explore different workouts with details such as muscle groups, equipment, difficulty, duration, sets, and reps.
* 🔍 Browse and find suitable workouts easily.
* ➕ Add workouts to your personal workout plan.
* ➖ Remove workouts from your personal plan when needed.
* 💾 Save workouts for quick access later.
* 📋 View detailed workout instructions and information.
* 📱 Fully responsive design for desktop, tablet, and mobile devices.
* 🎨 Modern dark-themed user interface with a clean and simple design.

## 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* React Icons
* JSON

## 🚀 How to Download and Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/shamsu082277/fitness-log.git
```

### 2. Go to the Project Folder

```bash
cd fitness-log
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Project

```bash
npm run dev
```

The project will be available at:

```text
http://localhost:3000
```
